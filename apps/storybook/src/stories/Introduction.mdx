# UIX

**AI Agent 应用的 React 组件库**

UIX 是专为构建 AI Agent 交互界面设计的组件库，基于 **UIX Protocol** 实现 AI 输出到 UI 渲染的标准化转换。

> 💡 查看 [Protocol Demo](https://uix.deepractice.org/) 了解 UIX 的核心工作原理

## 特性

- 🎨 **双主题系统** - Rational（理性蓝）& Sentient（感性金）
- 🧩 **组合式 API** - 灵活组合，按需定制
- ⚡ **流式支持** - 原生支持 AI 流式响应
- 🔧 **工具展示** - 内置 Tool Use 状态展示组件
- 📱 **响应式** - 适配桌面和移动端

## 安装

```bash
pnpm add @uix-ai/agent
```

## 快速开始

```tsx
import {
  ChatMessage,
  ChatMessageAvatar,
  ChatMessageContent,
  ChatInput,
  ChatInputTextarea,
  ChatInputSubmit,
} from '@uix-ai/agent'

function Chat() {
  return (
    <div>
      <ChatMessage role="assistant">
        <ChatMessageAvatar name="Claude" />
        <ChatMessageContent>Hello! How can I help you?</ChatMessageContent>
      </ChatMessage>

      <ChatInput onSubmit={handleSubmit}>
        <ChatInputTextarea placeholder="Type a message..." />
        <ChatInputSubmit />
      </ChatInput>
    </div>
  )
}
```

## 组件分类

### 聊天核心
- **ChatMessage** - 消息气泡（组合式）
- **ChatInput** - 输入框（组合式）
- **MessageList** - 消息列表容器

### AI 状态
- **StreamText** - 流式文本渲染
- **ThinkingIndicator** - 思考指示器
- **Avatar** - 头像（支持动画状态）

### 工具 & 来源
- **ToolResult** - 工具执行结果
- **SourceBlock** - RAG 来源引用

### 辅助组件
- **MentionPopover** - @提及弹窗
